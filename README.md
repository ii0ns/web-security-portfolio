# Web Security Portfolio

This repository documents my hands-on progression toward becoming a web application security tester. It contains full security assessment reports, security automation tools I've built, technical documentation, and reusable hardening checklists — all produced through structured, self-directed lab work.

I'm early in this specialization. Rather than list claimed skills, this repository is meant to let the work speak for itself: each entry below is something I actually built or tested, with a report or writeup you can read end to end.

## Current Focus

Web application security testing (OWASP Top 10, Burp Suite / OWASP ZAP, authentication & authorization testing, REST API security), with Python-based tooling to support assessments. Networking, Linux hardening, and cloud security are planned next steps — see the roadmap below.

## Repository Structure

| Folder | Contents |
|---|---|
| [`Security-Assessments/`](./Security-Assessments) | Full assessment reports (executive summary, methodology, findings, risk ratings, recommendations) |
| [`Python-Tools/`](./Python-Tools) | Security tooling I built, most of it used directly in an assessment above |
| [`Documentation/`](./Documentation) | Concept write-ups (JWT, CORS, SQLi, CSRF, etc.) written to demonstrate — not just restate — understanding |
| [`Security-Checklists/`](./Security-Checklists) | Reusable hardening checklists for Linux, Nginx, Docker, and similar |
| [`Screenshots/`](./Screenshots) | Supporting evidence, organized per project |

Each folder has its own README explaining what's in it.

## Scope & Ethics

All testing in this repository was performed against:
- Intentionally vulnerable applications designed for security training (e.g. OWASP Juice Shop, DVWA, WebGoat), or
- Personal lab environments I own and control, or
- CTF challenges whose rules explicitly permit public writeups.

No client work, real-world targets, or systems tested without explicit authorization appear here. No credentials, sensitive data, or unauthorized findings are published in this repository.
